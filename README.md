# my-app

Stack: React 19, Vite, TypeScript, Tailwind CSS, Redux Toolkit, React Router, TanStack Form, Zod, Prettier.

## Getting started

```bash
npm install
npm run dev
```

## Scripts

- `npm run build`
- `npm run preview`
- `npm run typecheck`
- `npm run format`
- `npm run format:check`

## Push to GitHub

Create an empty repository on GitHub, then:

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/<your-username>/my-app.git
git push -u origin main
```
